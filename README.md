# The God Who Forgot

A story-driven, non-combat 2D pixel-art RPG built with Godot for Android.

## First playable milestone: The Empty Place
- A tiny explorable corner of Hollowmere
- Touch-friendly movement
- Iria and a short dialogue scene
- Inspectable clues: an empty bowl and a faded drawing
- A journal entry and local save
- One meaningful dialogue choice

This is an early scaffold, not the finished game. Placeholder art is temporary.

## Constraints
- Godot 4.x; Compatibility renderer for mobile
- Android-phone-first workflow; no desktop-only tools assumed
- Free assets only, with licenses checked before inclusion
- Small, testable milestones
- Use main as the working branch unless we explicitly agree otherwise

## Folders
- scenes/ — game scenes
- scripts/ — GDScript logic
- assets/ — art, audio, fonts, and attribution notes
- docs/ — design notes and checkpoints

Open this folder in Godot 4.x and run the main scene. More files will be added in small, testable steps.
